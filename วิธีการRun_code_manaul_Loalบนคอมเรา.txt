Open: http://localhost:8005

Podman (run instead of local uvicorn):
podman compose up -d --build
Traffic: http://localhost:8005 -> nginx:80 -> artemis:8000
Only Nginx publishes a host port. Artemis is internal to the compose network.
Upload limit through Nginx: 50 MB (client_max_body_size in nginx.conf).

Check status:
podman compose ps

View logs:
podman compose logs -f nginx artemis

Remote access: http://<server-ip>:8005/login-page
Nginx forwards to artemis:8000 on the internal container network.
SSO callback follows the incoming host and port by default.
For a public HTTPS domain, set SSO_CALLBACK_URL=https://<domain>/home
in .env (see .env.example), then recreate with:
podman compose up -d --build --force-recreate
